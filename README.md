# 🔍 Deepak Vision AI

A browser-based computer vision application that detects supported
objects in images, draws bounding boxes, calculates confidence scores,
analyzes dominant colors, and displays image properties.

## ✨ Features

- Object detection using TensorFlow.js and COCO-SSD
- Bounding boxes around detected objects
- Object counts and confidence scores
- Adjustable detection confidence threshold
- Dominant color analysis
- Image dimensions and aspect ratio
- Image orientation and file size information
- Automatic scene summaries based on detected objects
- Searchable object detection results
- Downloadable annotated images
- Responsive dark-themed dashboard

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- TensorFlow.js
- COCO-SSD
- Python
- FastAPI
